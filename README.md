# Student Data Analyzer

A Python data analysis project that processes student performance data from a CSV file and produces statistics and visualizations.

## Features

- Load student data from CSV
- Calculate average scores by subject
- Find highest and lowest scores
- Calculate individual student averages
- Identify the top-performing student
- Analyze individual subjects
- Generate score visualizations
- Save charts as PNG images

## Technologies

- Python
- pandas
- matplotlib
- CSV

## How to run

1. Make sure Python 3 is installed.
2. Install the required libraries:

```bash
python3 -m pip install pandas matplotlib
